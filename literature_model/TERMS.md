# Process Flowsheet Stage Reference

Use this document to identify and categorize equipment/stages when extracting from process flowsheets. Match flowsheet terms to the standard_id using the synonyms listed.

---

## Comminution

### crusher
Size reduction using mechanical force.
- Synonyms: crushing, primary_crusher, secondary_crusher, tertiary_crusher, jaw_crusher, cone_crusher, gyratory_crusher, chancadora, chancadora_primaria, chancadora_secundaria, chancadora_terciaria, crushing_unit, crusher_dump_hoppers, primary_crusher_discharge_feeder, secondary_crushing_screen

### mill
Fine grinding using rotating drums with grinding media.
- Synonyms: grinding, ball_mill, sag_mill, rod_mill, molino_bolas, grinding_unit, mill_classification

### regrind
Secondary grinding to improve mineral liberation.
- Synonyms: regrind_mill, regrind_cyclone, copper_regrind, zinc_regrind, pyrite_regrind, copper_regrind_mill, pyrite_regrind_mill, regrind_unit

### screen
Size classification through mesh/apertures.
- Synonyms: vibrating_screen, grizzly, zaranda, pebble_wash_screen, loaded_carbon_screen, barren_screen, carbon_safety_screen, kiln_dewatering_screen, carbon_sizing_screen

### agglomeration
Binding fine particles into larger masses for heap leaching.
- Synonyms: crushing_screening_agglomeration

### cyclone
Size classification using centrifugal force.
- Synonyms: hydrocyclone, cyclone_cluster, tailing_cyclone_cluster, classification, ciclones, classifier

### input
Initialization of the process with input feed
- Synonyms: rom_stockpile, R.O.M. STOCKPILE

## Concentration

### flotation
Mineral separation using air bubbles and reagents.
- Synonyms: rougher_flotation, scavenger_flotation, cleaner_flotation, rougher_flotation_cells, copper_flotation, zinc_flotation, lead_flotation, pyrite_flotation, copper_rougher_flotation, copper_cleaner_flotation, zinc_rougher_flotation, zinc_cleaner_flotation, pyrite_rougher_flotation, pyrite_cleaner_flotation, moly_rougher_flotation_cells, copper_rougher_cleaner, copper_1st_cleaner, copper_2nd_cleaner, copper_3rd_cleaner, zinc_1st_cleaner_flotation, zinc_2nd_cleaner_flotation, zinc_3rd_cleaner_flotation, moly_1st_cleaner_column_cell, moly_2nd_cleaner_column_cell, moly_3rd_cleaner_column_cell, moly_rougher_conditioning_tank, flotation_unit, flash_flotation

### magnetic_separation
Separation using magnetic properties of minerals.
- Synonyms: magnetic_separator, wet_magnetic_separation, dry_magnetic_separation, lims, whims

### thickener
Solid-liquid separation by gravity settling.
- Synonyms: espesador, concentrate_thickener, tailings_thickener, copper_concentrate_thickener, copper_moly_thickener, moly_concentrate_thickener, copper_sulfide_thickener, tmf_dewatering_thickener, thickening, concentrate_thickening, solid_liquid_separation, counter_current_decantation, ccd, copper_moly_separation

### filter
Dewatering by filtration.
- Synonyms: filter_press, vacuum_filter, filtro, filtro_pb, filtro_zn, filtro_cu, concentrate_filtration, filtration, moly_concentrate_filter, copper_concentrate_filter, carbon_fines_filter, sludge_filter_press, baghouse, scrubber, kiln_scrubber, scrubber_carbon_bed

### cell
Electrochemical or specialized processing cells.
- Synonyms: electrowinning_cells, column_cell, celda, celda_primaria, celda_limpieza, pyrite_scavenger_cells

- Synonyms: gravity_concentration, gravity_circuit, gravity_separation, jig, shaking_table, spirals, dms_plant, dense_media_separation

## Hydrometallurgy

### leach
Dissolving metals using chemical solutions.
- Synonyms: leaching, heap_leach, tank_leaching, heap_leach_solution_handling, lixiviacion

### adsorption
Metal recovery onto activated carbon or resin.
- Synonyms: cic, cic_columns, cip, cil, carbon_in_column, carbon_in_pulp, carbon_in_leach

### precipitation
Metal recovery by chemical precipitation.
- Synonyms: precipitation_reactor, cementation

### electrowinning
Electrochemical metal recovery from solution.
- Synonyms: electrowinning_cells, ew, copper_cathodes

### elution
Stripping adsorbed metals from carbon or resin.
- Synonyms: elution_regeneration, carbon_elution_regeneration, carbon_stripping, elution_electrowinning, elution_and_electrowinning, acid_wash

### solvent_extraction
Selective metal transfer between immiscible liquid phases.
- Synonyms: sx, sx_extraction, sx_stripping, copper_stripping

### merrill_crowe
Zinc dust precipitation for gold/silver recovery from solution.
- Synonyms: merrill_crowe_precipitation, zinc_precipitation

### ion_exchange
Metal recovery using ion exchange resins.
- Synonyms: ix, ion_exchange_columns
